# ITAL-1378: Computer Vision Applied to Artificial-Intelligence

Course Description: This course was specifically designed to teach the complex nature of how machines interpret, analyze, understand, and apply Visual Data similar to the way humans see the world. This course facilitates the applied understanding and application of Computer Vision, and all of its components. 

README purpose: This file is to showcase the projects that were completed throughout the course. This Repository contains the actual [.ipnyb] files.

-[L01: Exploring Real-World Applications of Computer Vision]: 
  -[Description]: This Lab covered the basic principles in how Computer Vision can be; and already is implemented into the real world.

-[L02: Image Processing Fundamentals]: 
  -[Description]: Lab 02 covered the basic fundamentals of Image Processing. This lab taught me how it connects with several aspects across both Computer Vision applications and real world scenarios.

-[L03: Using Classic Machine Learning in Computer Vision]: 
  -[Description]: LAB 03 covered Machine learning understanding, and showing it's pros and cons. It also showed how important it is to train models when creating idealistic testing environments for models as well. 

-[L04: Chihuahua or Muffin]: 
  -[Description]: This Lab had me run the Chihuahua vs Muffin experiment, a test to show how computer vision can often fail to distinguish features that look similar, even if the objects in the picture are completely different. 

-[L05: Chihuahua or Muffin with CNN]: 
  -[Description]: This lab was a continuation of L04, only instead now subbing out a Traditional Neural Network for a CNN. This lab showed the distinct key differences between the two.

-[L06: Object Detection using Transfer learning]: 
  -[Description]: This lab covered distinctions between Classification, Detection, and Segmentation. This lab integrated into our final by showing how each method would be essential to understand in order to make a decision on what we wanted to do, and how to build around it.

-[L08: Visual Language Models (VLMs)]: 
 -[Description]: This Lab showed us more advanced metrics computer vision can do, and showed what happens when we want a picture broken down further before and analyzed, allowing us to understand the key distinct features of a VLM, and what is essential in order to making this model work.
